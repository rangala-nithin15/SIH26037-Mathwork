# results/

**This folder is empty, and that is correct.**

---

## Why it is empty

Everything in this folder is **generated by execution**. Nothing in this project has been executed, so nothing exists here.

No figure, no metric, no table, no `.mat` file and no screenshot has been placed here in advance. There is nothing to find because there is nothing to find yet.

## What will appear here

| Produced by | Output |
|---|---|
| `runComparison(..., struct('saveDir','results'))` | `comparison_<timestamp>.mat` |
| `runAblation(..., struct('saveDir','results'))` | `ablation_<timestamp>.mat` |
| `runAllExperiments(seeds)` | `full_evaluation_<timestamp>.mat` |
| Your own plotting | `figures/*.png` |
| Screen capture of `demoScenario` | `videos/*.mp4` |

## Rules for this folder

1. **Nothing goes in here that was not produced by a run.** No hand-written numbers, no illustrative placeholders, no "expected" values.
2. **Nothing in here gets committed to version control.** Results are reproducible from source; committing them invites stale numbers being quoted long after the code has changed.
3. **Nothing in here gets transferred between machines.** Regenerate on the machine that will report them.
4. **Every result carries its provenance.** `computeMetrics` attaches a `.provenance` struct recording the sensor model, the vehicle model, the profile, the seed count, and `realWorldClaim = false`. Do not separate a number from it.

## Reproducing any result

Every run is seeded. Given the scenario, planner, configuration and seed, a result reproduces exactly:

```matlab
setupPaths;
[log, M] = runScenario('village', @irpscPlanner, [], struct('seed', 42));
```

If a number in the report cannot be reproduced this way, it does not belong in the report.

## Before generating anything

Run the tests first:

```matlab
runAllTests('unit')
```

Numbers produced by code whose tests have not passed are not worth reporting.
